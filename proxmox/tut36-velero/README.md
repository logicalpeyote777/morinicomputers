# tut36 — velero

Scripts y manifiestos del tutorial «Backup y disaster recovery de tu clúster Kubernetes
sobre Proxmox con Velero» de Morini Computers (YouTube).

- `app.yaml` — la app de empresa: MariaDB + PVC + Secret + Service (namespace `empresa`)
- `seed.sql` — la tabla de facturas que destruimos y recuperamos
- `credentials.example` — plantilla de credenciales S3/MinIO para Velero
- `comandos.md` — todos los comandos del vídeo, en orden

Laboratorio propio; solo fines educativos.
